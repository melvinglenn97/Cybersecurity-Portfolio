
# Linux Fundamentals — Command Reference

A record of Linux commands and file-management skills practiced during foundational Linux training.

## Navigation
- `whoami` — Identify the current user.
- `pwd` — Display the current directory.
- `ls` — List directory contents.
- `ls -l` — Display detailed file information.
- `ls -R` — List directory contents recursively.
- `cd` — Navigate between directories.

## File and Directory Management
- `mkdir` — Create directories.
- `touch` — Create empty files.
- `mv` — Move or rename files.
- `cp` — Copy files.
- `rm` — Remove files.
